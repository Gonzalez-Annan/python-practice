# Python Practice

A collection of small Python exercises, algorithm implementations, numerical examples, and technical experiments.

The repository is organized by topic so that individual examples can be inspected and executed independently.

## Topics

- Algorithms
- Data Structures
- Numerical Methods
- Robotics
- Computer Vision
- Signal Processing
- Networking
- Utilities

## Running an Example

Most examples use only the Python standard library.

Example:

    python3 robotics/pid_controller_01.py

or:

    python3 numerical_methods/rk4_01.py

## Purpose

This repository is used as a collection of Python practice exercises and small technical implementations.

The examples are intentionally kept compact so that each concept can be understood independently.
