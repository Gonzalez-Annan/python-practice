# Motor Characterization Practice

Small Python exercises based on practical work with a servo motor, EtherCAT drive, and ROS 2.

## Topics

- Encoder counts to joint position
- rad/s, rpm, and drive-unit conversions
- Per-mille rated torque to Nm
- Coulomb friction
- Viscous friction
- Stribeck friction
- Least-squares fitting
- Nonlinear curve fitting
- Velocity/torque CSV analysis

## Files

- `01_drive_unit_conversions.py`
- `02_friction_model_demo.py`
- `03_analyze_velocity_torque_csv.py`

These are reusable practice examples rather than hardware-specific thesis code.
